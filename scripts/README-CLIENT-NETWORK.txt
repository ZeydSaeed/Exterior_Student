================================================================================
  ربط 5 لابتوبات بنظام الطلبة عبر سويج 1405-8 + محول USB QTS1081B
  الحاسبة الرئيسية = السيرفر (Herd + XAMPP + MySQL + المشروع)
  اللابتوبات = عميل فقط (Chrome يفتح الموقع من السيرفر)
================================================================================

── 1) المعدات ──
  • حاسبة رئيسية واحدة (Windows) فيها المشروع + Herd + XAMPP
  • سويج شبكة (مثلاً 1405-8) — غير مُدار (Unmanaged): لا يحتاج إعداد IP للسويج
  • 5 لابتوب + 5 محول USB إلى LAN (QTS1081B)
  • 6 كابلات شبكة (سيرفر + 5 لابتوب)
  • Google Chrome على كل جهاز

── 2) تثبيت محول QTS1081B على كل لابتوب ──
  1. وصّل المحول بمنفذ USB
  2. ثبّت التعريف من CD/موقع الشركة أو Windows Update
  3. في «إعدادات Windows → الشبكة → Ethernet» تأكد أن المحول «Connected»

── 3) توصيل السويج (Physical) ──
  منفذ 1  ←  الحاسبة الرئيسية (كابل شبكة مباشر أو من كرت LAN)
  منفذ 2  ←  لابتوب 1
  منفذ 3  ←  لابتوب 2
  منفذ 4  ←  لابتوب 3
  منفذ 5  ←  لابتوب 4
  منفذ 6  ←  لابتوب 5
  (السويج غير المُدار: لا IP للسويج — فقط توصيل الكابلات)

── 4) عناوين IP ثابتة (مهم — السويج لا يوزّع DHCP) ──
  الشبكة المقترحة: 192.168.10.x  |  Subnet: 255.255.255.0  |  Gateway: (فارغ)

  الجهاز              IP              DNS
  ─────────────────────────────────────────
  السيرفر (رئيسي)     192.168.10.1    (فارغ)
  لابتوب 1            192.168.10.11   (فارغ)
  لابتوب 2            192.168.10.12   (فارغ)
  لابتوب 3            192.168.10.13   (فارغ)
  لابتوب 4            192.168.10.14   (فارغ)
  لابتوب 5            192.168.10.15   (فارغ)

  Windows: Settings → Network → Ethernet → Edit IP assignment → Manual → IPv4

── 5) إعداد الحاسبة الرئيسية (السيرفر) ──
  1. ثبّت Herd + XAMPP + المشروع كما هو حالياً
  2. وصّل كابل السويج بمنفذ Ethernet على السيرفر (يجب أن يظهر Connected)
  3. شغّل مرة واحدة كمسؤول:
       scripts\configure-server-herd-lan.bat
     (يعيّن IP 192.168.10.1 على Ethernet + nginx للشبكة + جدار الحماية)
  4. أو شغّل silent-start-app.vbs كمسؤول (يعيد تعيين IP عند الحاجة ويشغّل MySQL+nginx)
  5. تأكد محلياً: http://exterior_student.test
  6. من السيرفر اختبر: ping 192.168.10.11 (بعد ضبط لابتوب واحد)

── 6) ملف hosts على كل لابتوب (مرة واحدة) ──
  افتح Notepad «كمسؤول» → افتح:
    C:\Windows\System32\drivers\etc\hosts

  أضف سطراً (IP السيرver):
    192.168.10.1    exterior_student.test

  احفظ الملف.

── 7) ملف التشغيل على اللابتوبات ──
  انسخ إلى سطح المكتب (أو USB):
    scripts\silent-start-client.vbs
    scripts\students-app.ico  (اختياري للأيقونة)

  اختصار سطح المكتب:
    • Target: wscript.exe "C:\Users\...\Desktop\silent-start-client.vbs"
    • أو انقر مرتين على الملف .vbs

  إذا غيّرت IP السيرفر، عدّل السطر في أعلى الملف:
    Const SERVER_IP = "192.168.10.1"

── 8) على السيرفر فقط — ملف التشغيل الكامل ──
    scripts\silent-start-app.vbs
  (يشغّل MySQL + Herd/nginx + Chrome — لا تنسخه للابتوبات)

  مهم: ملف LAN في Herd يستمع على 192.168.10.1:80.
  إذا لم يكن هذا الـ IP مفعّلاً على السيرفر، السكربت يعطّل إعداد LAN
  مؤقتاً حتى يعمل الموقع محلياً على http://exterior_student.test
  وعند توفر 192.168.10.1 يعيد تفعيل إعداد الشبكة تلقائياً.

── 9) اختبار ──
  1. على السيرفر: شغّل silent-start-app.vbs
  2. على لابتوب: ping 192.168.10.1  →  Reply
  3. على لابتوب: افتح Chrome → http://exterior_student.test
  4. أو شغّل silent-start-client.vbs

── 10) بديل: ExteriorStudent.exe (WebView2) ──
  انسخ مجلد scripts\app-host\ إلى اللابتوب وشغّل:
    ExteriorStudent.exe http://exterior_student.test
  (يتطلب WebView2 Runtime + hosts كما فوق)

── استكشاف الأخطاء ──
  • Ping فاشل → كابل / IP / محول USB
  • Ping ناجح لكن الموقع لا يفتح → جدار حماية السيرفر أو Herd متوقف
  • يظهر AdminerEvo بدل البرنامج → شغّل configure-server-herd-lan.bat مرة أخرى
    (يستعيد herd.conf ويضيف ملف LAN منفصل)
  • رسالة hosts → أضف السطر في ملف hosts
  • Chrome لا يوجد → ثبّت Google Chrome
